Completed a CodeByte challenge focused on implementing a calculator application using React. One of the main challenges I faced was improving the responsiveness of the calculator buttons, as users were initially unable to clearly see which numbers and operations they selected. I also needed to fix layout and alignment issues to ensure the numbers and operators were displayed properly and consistently.

This full-stack application allowed me to strengthen both my frontend design and backend logic skills. While I already understood the core backend functionality, I focused heavily on creating a clean and user-friendly interface that matched the design vision I had in mind.

I enjoy solving problems under time pressure, and I successfully completed the challenge in less than 1 hour and 30 minutes.
